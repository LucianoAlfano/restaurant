# NextDay Digital

Complete static website with a homepage, theme gallery, and eight fictional industry demos.

## Preview

```bash
python -m http.server 8765
```

Open `http://localhost:8765`. No build step or dependencies.

## Key files

- `index.html`: sales homepage
- `themes.html`: filterable theme gallery
- Eight demo pages: restaurant, landscape, auto, bakery, fitness, salon, contractor, professional
- `style.css`, `app.js`: shared design and interactions
- `404.html`, `robots.txt`, `sitemap.xml`
- `assets/`: optimized WebP and JPEG images

All demo businesses and details are fictional.
